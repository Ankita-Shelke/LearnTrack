LearnTrack

Console-based Student & Course Management System built using Core Java.
The application allows administrators to manage students, courses, and enrollments in a structured and modular way.

Features
1. Add Student
2. View Students
3. Search Student
4. Deactivate Student
5. Add Course
6. View Courses
7. Enroll Student
8. View Enrollments
0. Exit

How to Run
javac com/airtribe/learntrack/ui/Main.java


java com.airtribe.learntrack.ui.Main
