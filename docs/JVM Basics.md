JVM Basics

JDK, JRE, and JVM
JDK (Java Development Kit) is used by developers to write and compile Java programs. It contains development tools like the compiler (javac) and also includes the JRE.

JRE(Java Runtime Environment) provides the environment required to run Java applications. It contains the JVM and core libraries.

JVM (Java Virtual Machine) is responsible for executing Java bytecode. It converts bytecode into machine-specific instructions so that the program can run on any system.

What is Bytecode?

Bytecode is an intermediate code generated by the Java compiler. It is not specific to any operating system and is executed by the JVM.

Write Once, Run Anywhere

Java follows the principle of “write once, run anywhere” because Java programs are compiled into bytecode, which can run on any system that has a compatible JVM installed.
